# ShopStore - Дипломный проект

Дипломный проект интернет-магазин с витриной и админкой на React, Redux-Toolkit, TypeScript.

## Описание проекта
Этот проект разработан в рамках дипломной работы для демонстрации навыков разработки веб-приложений с использованием современных технологий. Проект включает в себя витрину для покупателей и административную панель для управления товарами, категориями и заказами.




## Стек

- React
- Redux-Toolkit
- TypeScript
- Firebase
- Адаптивная верстка

## Установка

Для запуска на локальной машине необходимо:</br>

1. Установить npm зависимости:</br>

```sh
npm install
```

2. Запустить в режиме разработки:</br>

```sh
npm run start
```

Если все прошло успешно, проект будет запущен на `http://localhost:3000`
